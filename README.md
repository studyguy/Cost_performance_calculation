# 工作性价比计算器（工效计算器）

把「这份工作到底值不值」量化成一个分数、一张雷达图，和一条扎心的评语。

单文件纯静态网页，零依赖、无后端、无构建。填几个数字，你的工作性价比立刻现形。

## ✨ 在线体验

https://studyguy.github.io/Cost_performance_calculation/

## 🎯 功能特性

- **六维加权评分**：薪资回报 · 时间成本 · 物质环境 · 人际氛围 · 发展空间 · 职业稳定，六个维度加权得出综合分
- **真实收入口径**：五险一金、简化个税、年终奖、隐形福利自动折算，「到手月薪 / 综合月入 / 年收入」实时可见
- **城市购买力折算**：同薪不同命？评分按所在城市生活成本修正（一线→四线五档）
- **通勤联动**：通勤时长滑块带实时数值与分级文案（远程 / 很轻 / 标准 / 偏长 / 极端），滑动即见
- **加班与年假**：无偿加班按程度惩罚时间分（劳动法 1.5~3 倍依据），年假 5~20 天可选
- **S~E 六级等第**：从「S 神仙工作」到「E 尽快跑路」，一眼看懂结果
- **实时计算**：改任何一个参数，评分与评语立即刷新，零延迟反馈
- **幽默评语**：每档评分配一条带梗的点评（这是本项目的灵魂）
- **六维雷达图**：Canvas 绘制，直观对比六个维度的优劣
- **档案系统**：保存评估结果（含自定义名称），下次打开直接对比（旧版本档案自动迁移重算）
- **多档对比**：勾选多份档案，雷达图 + 指标明细横向对比
- **趋势图**：查看历史评估的性价比变化曲线
- **深色模式**：一键切换，跟随系统偏好，选择持久保存
- **移动端适配**：窄屏自动单列布局

## 🧮 评分模型（v3 · 六维）

```
综合得分 = Σ( 六维子分 × 权重 ) ÷ ( 教育期望系数 × 年限期望系数 )
```

**六维与权重**：

| # | 维度 | 权重 | 内容 |
|---|---|---|---|
| 1 | 薪资回报 | 34% | 真实收入 ÷ 城市成本指数 → 购买力时薪对数曲线 |
| 2 | 时间成本 | 18% | 工时+通勤占用 × 年假修正 × 加班回报修正 |
| 3 | 物质环境 | 8% | 工作环境（写字楼/工厂/户外等） |
| 4 | 人际氛围 | 12% | 团队/领导/同事氛围 |
| 5 | 发展空间 | 14% | 晋升潜力 1-10 |
| 6 | 职业稳定 | 14% | 单位类型（体制内/大厂/外包等） |

**真实收入口径**（对名义薪资做三项修正，估算注明在页面提示里）：

- **五险一金**：社保个人固定 10.5%（养老 8%+医疗 2%+失业 0.5%），公积金按所选比例（5%~12%）扣除个人部分；单位缴存部分计入「综合月入」（HR 谈薪的现金+公积金口径）
- **简化个税**：按年度综合所得计税（减除 6 万，3%~35% 七级速算，忽略专项附加）
- **城市购买力**：一线 1.32 / 新一线 1.15 / 二线 1.0 / 三线 0.88 / 四线及以下 0.75（二线为基准；依据城镇居民消费支出统计与房租比价）
- **年终奖与福利**：年终奖月数（0~6+）并入年现金收入；餐补/房补等隐形福利按档位折算月收入

**时间成本修正**：

- 年假：`245 / (250 − 年假天数)`（年 250 工作日基数，法定 5 天起）
- 加班回报：标准工时/依法付费为 1.0，无偿加班按程度 ×0.93/0.84/0.72（《劳动法》加班费 1.5~3 倍，无偿 = 时薪隐性打折）

**期望系数**（延续原版公式的哲学：同样的钱，期望越高越难拿高分）：

- 教育：非 211/985 本科 0.8 → 海外博士 2.2
- 年限：应届 0.95 → 12 年以上 1.2

**示例校准**（真实口径，二线基准）：15k×13薪+12% 公积金、双休 8h、通勤 40 分钟、写字楼、好团队、发展 5、本科 3 年 → 综合 84.5（A）；同配置改 996 无偿加班（11h×6 天）+ 硕士 8 年 → 49.5（C）。

**等级划分**：

| 等级 | 分数 | 评语 |
|---|---|---|
| S | ≥ 85 | 顶级配置！好好珍惜，别轻易跳槽 |
| A | ≥ 70 | 性价比相当高，稳步发展即可 |
| B | ≥ 55 | 中上水平，值得长期经营 |
| C | ≥ 40 | 平平淡淡，可边工作边留意机会 |
| D | ≥ 25 | 性价比偏低，建议提前规划后路 |
| E | < 25 | 投入产出严重失衡，认真考虑换赛道 |

> 评分模型迭代记录：初版为「时薪基数 × 环境 × 人际 ÷ 教育」；v2 改为四维加权并引入对数时薪曲线；v3 全面重构为六维（拆分环境/人际、新增职业稳定轴），并把名义薪资修正为「到手现金 + 单位公积金」的真实口径，再按城市购买力折算。评语一直保留幽默风格。
> 口径说明：个税未计专项附加、公积金按工资全额基数（未按 3 倍社平封顶），估算结果仅供参考，不构成税务/财务建议。

## 🚀 快速上手

1. 打开页面（或本地运行，见下）
2. 填月薪，选年限 / 教育投入，调工作时长 / 天数 / 通勤，选环境 / 人际 / 晋升空间
3. 右侧实时显示综合分、等级、评语与雷达图
4. （可选）「保存为档案」→ 「对比」页勾选多份档案横向比；「档案」页查看趋势

## 🔒 隐私说明

- **纯本地存储**：档案与主题保存在浏览器 `localStorage`，不上传任何服务器
- 无后端、无统计、无追踪
- 清除浏览器数据 = 清除档案，删除前请知悉

## 🛠 本地运行

项目是单文件静态页，任意静态服务器即可：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

或直接把 `index.html` 拖进浏览器（建议用本地服务器方式以获得最佳兼容性）。
