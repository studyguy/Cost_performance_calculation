# 工作性价比计算器（Cost-Performance Calculator）

> 把「这份工作到底值不值」量化成一个分数、一张雷达图，和一条扎心的评语 —— 单文件纯静态网页，零依赖、无后端、无构建，填几个数字立刻现形。

**[🧮 在线体验](https://studyguy.github.io/Cost_performance_calculation/)** · **[📦 源码仓库](https://github.com/studyguy/Cost_performance_calculation)**

---

## 📖 这是什么

拿到 offer 或动了跳槽念头时，「月薪多少」远不能回答「这份工作值不值」：996 的 20k 可能不如双休的 15k。本工具让你填几个数字（薪资、工时、通勤、环境、氛围、发展、稳定性），从**六个维度加权**算出综合分与 S~E 等第，配雷达图和带梗评语，把「性价比」这件事一次算清楚。

**纯本地运行**：档案与主题保存在浏览器 `localStorage`，无后端、无统计、无追踪；清除浏览器数据 = 清除档案。

## ✨ 核心功能

- **六维加权评分**：薪资回报 34% · 时间成本 18% · 物质环境 8% · 人际氛围 12% · 发展空间 14% · 职业稳定 14%
- **真实收入口径**：五险一金、简化个税、年终奖、隐形福利自动折算，「到手月薪 / 综合月入 / 年收入」实时可见
- **城市购买力折算**：按所在城市生活成本修正评分（一线 1.32 → 四线及以下 0.75，二线为基准）
- **通勤与加班联动**：通勤滑块带分级文案（远程 / 很轻 / 标准 / 偏长 / 极端）；无偿加班按《劳动法》1.5~3 倍加班费依据惩罚时间分
- **S~E 六级等第**：S ≥85「神仙工作」→ E <25「尽快跑路」，每档配一条幽默评语（本项目的灵魂）
- **实时计算**：改任何一个参数，评分、等第、评语、雷达图立即刷新
- **档案与对比**：保存多份评估档案，勾选后雷达图 + 指标明细横向对比，可查历史趋势曲线
- **深色模式 + 移动端适配**：跟随系统偏好并持久保存，窄屏自动单列布局

## 🧮 评分模型速览（v3 · 六维）

```
综合得分 = Σ(六维子分 × 权重) ÷ (教育期望系数 × 年限期望系数)
```

- **薪资回报**：真实收入 ÷ 城市成本指数 → 购买力时薪对数曲线
- **时间成本**：工时+通勤占用 × 年假修正 × 加班回报修正
- **期望系数**：教育（非 211/985 本科 0.8 → 海外博士 2.2）与工作年限（应届 0.95 → 12 年以上 1.2）——同样的钱，期望越高越难拿高分

**等级划分**：S ≥85 / A ≥70 / B ≥55 / C ≥40 / D ≥25 / E <25

> 模型迭代：初版「时薪基数 × 环境 × 人际 ÷ 教育」→ v2 四维加权 + 对数时薪曲线 → v3 六维重构 + 真实收入口径 + 城市购买力。
> 口径说明：个税未计专项附加、公积金按工资全额基数估算，结果仅供参考，不构成税务/财务建议。

## 🛠️ 技术实现

- **单文件静态页**：`index.html` 一个文件即整个应用（HTML + CSS + JS），零依赖、无构建
- **Canvas 雷达图**自绘，历史档案自动迁移重算（旧版本兼容）
- **隐私设计**：全部数据仅存 `localStorage`，删除前请自行导出/知悉
