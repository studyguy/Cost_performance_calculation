# 工作性价比计算器（工效计算器）

把「这份工作到底值不值」量化成一个分数、一张雷达图，和一条扎心的评语。

单文件纯静态网页，零依赖、无后端、无构建。填几个数字，你的工作性价比立刻现形。

## ✨ 在线体验

https://studyguy.github.io/Cost_performance_calculation/

## 🎯 功能特性

- **四维加权评分**：薪资回报 · 时间成本 · 环境舒适 · 发展空间，四个维度加权得出综合分
- **实时计算**：改任何一个参数，评分与评语立即刷新，零延迟反馈
- **通勤联动**：通勤时长滑块带实时数值与分级文案（远程 / 很轻 / 标准 / 偏长 / 极端），滑动即见
- **S~E 六级等第**：从「S 神仙工作」到「E 尽快跑路」，一眼看懂结果
- **幽默评语**：每档评分配一条带梗的点评（这是本项目的灵魂）
- **四维雷达图**：Canvas 绘制，直观对比四个维度的优劣
- **档案系统**：保存评估结果（含自定义名称），下次打开直接对比
- **多档对比**：勾选多份档案，雷达图 + 指标明细横向对比
- **趋势图**：查看历史评估的性价比变化曲线
- **深色模式**：🌙/☀️ 一键切换，跟随系统偏好，选择持久保存
- **移动端适配**：窄屏自动单列布局

## 🧮 评分模型（v2）

```
综合得分 = ( 薪资回报×40% + 时间成本×22% + 环境舒适×20% + 发展空间×18% )
           ÷ ( 教育期望系数 × 年限期望系数 )
```

| 维度 | 计算方式 | 权重 |
|---|---|---|
| 薪资回报 | 时薪对数曲线 `65 + 24×ln(时薪/40)`，区间 [5, 120] | 40% |
| 时间成本 | `理想占用(9h) / 实际占用(工时+来回通勤)` × 100，区间 [5, 100] | 22% |
| 环境舒适 | 物理环境系数 × 人际氛围系数 × 100 | 20% |
| 发展空间 | 晋升空间(1-10) × 10，上限 100 | 18% |

**期望系数**（延续原版公式的哲学：同样的钱，期望越高越难拿高分）：

- 教育：非 211/985 本科 0.8 → 海外博士 2.2
- 年限：应届 0.95 → 12 年以上 1.2（年限越长，对薪资的心理价位越高）

**等级划分**：

| 等级 | 分数 | 评语（节选） |
|---|---|---|
| S | ≥ 85 | 顶级配置！好好珍惜，别轻易跳槽 |
| A | ≥ 70 | 性价比相当高，稳步发展即可 |
| B | ≥ 55 | 中上水平，值得长期经营 |
| C | ≥ 40 | 平平淡淡，可边工作边留意机会 |
| D | ≥ 25 | 性价比偏低，建议提前规划后路 |
| E | < 25 | 投入产出严重失衡，认真考虑换赛道 |

> 评分模型迭代记录：初版为「时薪基数 × 环境 × 人际 ÷ 教育」；v2 改为四维加权，并将薪资封顶改为对数曲线（时薪越高仍有反馈），年限移入期望系数。评语一直保留幽默风格。

## 🚀 快速上手

1. 打开页面（或本地运行，见下）
2. 填月薪，选年限 / 教育投入，调工作时长 / 天数 / 通勤，选环境 / 人际 / 晋升空间
3. 右侧实时显示综合分、等级、评语与雷达图
4. （可选）「保存为档案」→ 「对比」页勾选多份档案横向比；「档案」页查看趋势

## 🔒 隐私说明

- **纯本地存储**：档案与主题保存在浏览器 `localStorage`，不上传任何服务器
- 无后端、无统计、无追踪
- 清除浏览器数据 = 清除档案，删除前请知悉

## 🛠 本地运行

项目是单文件静态页，任意静态服务器即可：

```bash
python3 -m http.server 8000
# 打开 http://127.0.0.1:8000/
```

或直接把 `index.html` 拖进浏览器（建议用本地服务器方式以获得最佳兼容性）。
